# SGFloodSense

SGFloodSense: A Gamified Mobile Application to Improve the Flash-Flood Preparedness Among Young Adults in Singapore. This mobile application has been created for the final-year project on the topic of CM3050 Mobile Development, “Developing a Mobile App for Local Disaster Preparedness and Response”.

## Features

- Email and password authentication using Firebase
- Learning Modules and Quiz to prepare users on flash flood topics
- Emergency preparedness checklist 
- Singapore weather forecast and live-flood information
- Community incident reporting with location
- Preparedness leaderboard and achievements

## Technologies

- React Native
- Expo
- Firebase Authentication
- Cloud Firestore
- Expo Location
- React Navigation
- React Native Maps

## Installation

Install the project dependencies:

```bash
npm ci
```

Start the Expo development server:

```bash
npx expo start
```
